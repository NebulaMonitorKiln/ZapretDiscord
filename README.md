> [!WARNING]
>
> ### Антивирусные срабатывания
>
> Антивирус может отреагировать на WinDivert.  
> Это средство перехватывает и фильтрует трафик, поэтому оно необходимо для работы zapret.
> WinDivert способны использовать как безопасные, так и вредоносные программы, однако сам инструмент вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Часть антивирусов относит компоненты WinDivert к инструментам повышенного риска или хакерским утилитам. В результате файл удаляется и помещается в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky это настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений лучше добавить нужную папку, но если вы не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Сначала активируйте безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличный от "Поставщика по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS в настройках самой системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется этот вариант.
   * На роутерах Keenetic включите параметр "Транзит запросов". Если отключить его, Secure DNS на компьютере может работать неправильно.

2. Скачайте zip- или rar-архив со [страницы последнего релиза](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите необходимый файл.
   * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для автоматического запуска перейдите в **`service.bat`**: `Install Service` -> выберите подходящую стратегию.

## ℹ️ Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** переключает режим обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  Возможные состояния:
    - `none` — IP-адреса не участвуют в проверке;
    - `loaded` — IP проверяются на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет текущий фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если процесс не появился, ознакомьтесь с [#522](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues/522).

### Не нашлась подходящая стратегия

1. Откройте командную строку с правами администратора.
2. Выполните по очереди:

   `netsh winsock reset`

   `netsh int ip reset all`

   `netsh winhttp reset proxy`

   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не подключается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
- Скопируйте весь текст из открывшегося Блокнота.
- Откройте файл `hosts` в появившемся каталоге через текстовый редактор, запущенный от имени администратора.
- Добавьте скопированные данные в конец `hosts` или замените ими ранее добавленные аналогичные строки.
- Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работоспособность не гарантируется. При отсутствии результата используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/NebulaMonitorKiln/tg-ws-proxy) или публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который какое-то время работал, позднее может перестать помогать после его обнаружения.
> В репозитории собрано много стратегий. Если ни одна не подходит, создайте новую на основе одной из существующих и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок.
- Проверьте, внесён ли нужный адрес в списки доменов или IP.
- Попробуйте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительные сведения есть в [#765](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите компьютер.
- Выполните `service.bat` -> `Remove Services`.
- Затем запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите `Y`.
- Удалите каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу есть флажок разблокировки, установите его и нажмите применить, затем OK.
- Распакуйте архив в новую папку в корне диска, используя путь без пробелов и специальных символов.
- По очереди запускайте разные скрипты `general`. Проверяйте интернет-ресурсы: если они не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После выбора рабочего варианта установите его в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение перестало работать при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Инструкция находится [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Получите имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив полученное имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Запустите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается сайт YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/NebulaMonitorKiln/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не подключаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Для начала используйте общий порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Списки для обхода расширяются через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
