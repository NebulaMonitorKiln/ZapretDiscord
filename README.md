>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы относят компоненты WinDivert к потенциально опасным классам или хакерским инструментам, после чего удаляют файл и помещают его в карантин. В таком случае детект обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений предпочтительно добавить исключение, но если вы не полностью понимаете последствия, отключите обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках самой ОС - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это предпочтительный вариант.
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут завершиться проблемами.

2. Получите zip/rar-архив на [странице последнего релиза](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот этап можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc).</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб.
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** - включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Значение в скобках показывает текущее состояние: включено или выключено.
  - **`IPSet Filter`** - выбор режима обхода сервисов, перечисленных в `ipset-all.txt`.  
  Это помогает при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках отображается текущий режим:
    - `none` - ни один IP не проверяется
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** - замена используемого фейка на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>.
  - **`Check for Updates`** - ручная проверка наличия обновлений.
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает внезапно переставший работать клиент.
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`.
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который виден на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию
- Откройте командную строку с правами администратора.
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Веб-версия Telegram не подключается
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота.
  - Откройте текстовым редактором файл `hosts` в появившейся папке; редактор нужно запустить от имени администратора.
  - Вставьте скопированное в конец `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните изменения и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работа не гарантируется. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/NebulaMonitorKiln/tg-ws-proxy) либо любой публичный прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Работа стратегий со временем может прекращаться.**
> Вариант, который некоторое время работал, может перестать помогать после его обнаружения.
> В репозитории собрано много стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок.

- Убедитесь, что нужный ресурс присутствует в списках доменов или IP-адресов.

- Проверьте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- См. [#765](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце ответьте Y.
- Удалите старую папку zapret.
- Скачайте свежую версию на [странице релизов](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть "Разблокировать", включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте доступ к ресурсам. Если соединение не работает, закройте программу через иконку замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение перестало работать при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Воспользуйтесь инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Отключите блокировщик рекламы: известно, что YouTube начал против них бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён.
- Сначала определите стратегию, на которой открывается сайт YouTube, и запустите её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, используйте её.
- Если браузер также не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/NebulaMonitorKiln/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Игры не подключаются

Игры используют разные сетевые схемы, поэтому проверить и исправить каждую из них невозможно.

Попробуйте следующий общий порядок:
- через `service.bat` обновите ipset и активируйте `Game Filter`;
- если это не поможет, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

- Опишите её [здесь](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Новые адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
